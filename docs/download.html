Download The Grinder

Releases of The Grinder are published on the GitHub releases page. Each release has a single distribution zip, grinder-version-binary.zip, which holds everything needed to run The Grinder. The source code is in the same GitHub repository.

Expand the zip with unzip, WinZip or similar. It creates a grinder-version directory containing:

  • lib/: grinder.jar and the jar files it depends on.
  • startConsole.sh, startAgent.sh and startProxy.sh: start the console, an agent and the TCPProxy. They read setGrinderEnv.sh; put site settings in setGrinderEnv.local.sh.
  • updateGrinder.sh: updates an unpacked installation to a newer release zip, replacing lib/ and the shipped scripts and leaving your own files in place.
  • examples/: example scripts and a sample grinder.properties.
  • etc/: the XSL and XSD files the TCPProxy uses to turn a recording into a script.
  • contrib/: contributed extras.

The Getting Started guide explains what to do next.

What else do I need?

To run The Grinder: Java Standard Edition 21, equivalent, or later.

To build it from source: Java 21 or later and Apache Maven 3.9 or later. mvn -B verify builds everything, runs the tests and writes the distribution zip to grinder/target/.

Using The Grinder with Maven

The Grinder jar files are not published to Maven Central. To depend on them from a Maven build, build The Grinder from the source code with mvn -B -DskipTests install, which installs the jar files and the distribution zip into your local Maven repository.
