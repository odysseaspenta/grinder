Support

Questions, bugs and contributions

Ask questions and report bugs on the GitHub issue tracker. Please include The Grinder and Java versions, the relevant part of your grinder.properties and script, and the worker or console log.

Bug fixes and enhancements are welcome as pull requests; see contributing.

The Grinder is free software. No one is under any obligation to fix your problem. If all else fails, you have the source.

Mailing list archives

The original project's grinder-use, grinder-development and grinder-announce mailing lists on SourceForge are no longer the place to get help with this release, but their archives hold many years of answers.
